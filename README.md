# Forkop Extra Rules

Small sing-box source rule set containing domains used by the owner's previous
router configuration but not covered by `itdoginfo/allow-domains`' current
`russia_inside` list.

Raw URL:

`https://raw.githubusercontent.com/yakizaoo/forkop-extra-rules/main/extra.json`

SoundCloud, Discord, YouTube, Telegram, TikTok, Meta, Twitter, OpenAI and the
main WhatsApp domains are already present in `russia_inside` and are therefore
not duplicated here.
